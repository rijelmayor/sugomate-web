# SUGOMATE Web

Public website and app-download landing page for SUGOMATE — Imong sugo, among ihatod.

## Stack
- Next.js 15 / React 19 / TypeScript
- Tailwind CSS v4
- Vercel hosting
- Supabase integration planned for the marketplace backend phase

## Development
```bash
npm install
npm run dev
```

See `.env.example` for future backend environment variables.
